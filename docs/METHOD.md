# 申诉主题分类与分送：方法、口径与运维

本系统在承办员首读前把多主题来件分流到对应承办桌。**只做分送建议，不直接
作出处罚或裁决。** 全程本地运行，仅依赖 Python 3.11 标准库，不访问网络、
不调用外部模型服务，不使用真实文本（资料为本地合成记录）。

## 1. 总体流程

```
资料(CSV) → 目录版本 → 转发组 → 时点标签视图(PU) → 特征/三候选模型
        → 滚动窗口(训练/选型/独立复核) → 桌级准入 → 当周分送 → 协调员视图
```

运行：

```sh
python3 -I run_pipeline.py --data data --out reports --today 50
python3 -I -m unittest discover -s tests -v
```

`-I` 隔离模式保证不会从数据目录或当前目录加载同名模块（防止数据目录里的
`json.py` 之类被 import），`src` 由入口脚本显式加入路径。

## 2. 关键业务口径（不可违反的不变量）

### 2.1 多标签，不是单分类
一封信可同时问退费和质疑宣传。系统在**请求段**级别分类（按 `；` 切分），
每个主题独立判定，分给一个桌不会让另一项请求消失。模板前缀
`麻烦帮我查这件事，` 是渠道固定话术，先剥离再抽取特征。

### 2.2 PU 学习：未复核不是负例
- `labels.csv` 只记人工逐项判定，**空缺表示未知，不是阴性**；
- 资料中 74 封只复核一项的来件，其唯一结论全部是 `yes`，印证缺失项不能充负例；
- 只有明确 `yes`（正例）/`no`（负例）进入训练；
- `retracted` 在其 `known` 日之后撤销同项结论（见 x120 refund 于 day51 撤销）。

### 2.3 标签的时点可见性与适用期
- 训练只采信 `known <= 训练截点` 且未撤销的结论；
- 评估段来件的结论要到该段结束日才齐全，按段结束日过滤；
- 结论自带 `policy` 版本：v2 新子类只用 v2 结论训练。

### 2.4 目录分裂（v1 claim → v2 identity/promise）
- v2 下 `claim` 是**上位类、不挂桌**（`topics.csv` desk 为空）；
- 旧判读只有 claim 上位主题证据，**不能强行指定 identity/promise 的新桌面**；
- identity/promise 严禁继承任何 v1 claim 证据（测试
  `test_identity_promise_never_inherit_v1_claim` 固化）；
- 仅当主题同名且承办桌两版一致（refund→finance、contact→service），
  旧版正例才可作证据延续，并在 `evidence_sources` 留下血缘记录。

### 2.5 转发防泄漏
- 根来件由 `forwarding.csv` 显式登记，**不由文本是否相同判断**；
- 每个窗口独立定义角色（滚动窗口时间段重叠，同一来件可在首窗是复核件、
  在次窗是选型件）；
- 转发整组只要有一个成员落在选型/复核段，**整组都不进训练**，
  即使根件在训练段（见 `forwarding_audit.csv`，首窗排除 7 组、次窗 4 组）；
- 选型段只用于调阈值/选办法，独立复核段从不参与调参，复核段表现才是
  可对外声称的独立结果。

### 2.6 未登录表达（OOV）闸门
- 字符 2–3 gram 覆盖率相对**全量训练语料共享词表**计算（不能用单主题小词表，
  否则通用汉字 bigram 被误判 OOV）；
- 阈值 0.9 由 `analysis/calibrate_oov.py` 标定：标准短语覆盖率均为 1.0，
  已知新表达 x241 两段仅 0.05/0.0；
- OOV 表达即使模型有高置信也不自动送件，转人工补读。

## 3. 三个候选办法（每主题独立训练，逐主题比较）

| 办法 | 机制 | 可解释性 | 适用 |
| --- | --- | --- | --- |
| `rule` | 训练标签自动挖掘的高精度短语规则，不命中即弃权（不产出负概率） | 短语级，承办员可直接修订 | 证据少的新子类、强基线 |
| `nbayes` | 字符 n-gram 多项式朴素贝叶斯 | gram 对数似然比 | 小样本稳健 |
| `logreg` | 字符 n-gram 逻辑回归（批量梯度下降，L2 归一化） | gram 权重，正负贡献可读 | 样本充足时判别力强 |

**不是选总体分最高的一个**：逐主题比较，排序键为「误送数最少 → 覆盖最高 →
误送上界最低」。当前结果中第二窗 contact 选 nbayes、refund 选 logreg、
identity/promise 只能选 rule，说明比较真实生效。

## 4. 桌级准入：容忍度 + 最小支持量 + 实际覆盖

自动分送范围由**桌级**条件决定，而非模型总分：

1. 容忍度口径在 `limits.csv` 的 `known` 日才登记（本资料为 day44），
   在此之前没有自动准入依据，只积累证据；
2. 误送率用 **Wilson 单侧 95% 上界**而非点估计，避免小样本乐观偏差
   （10 件零误送的上界仍有 0.213，不能宣称误送率为 0）；
3. 跨独立复核批次累计送件数须达到该桌 `min_support`，且上界 ≤ `tolerance`。

当前所有桌面**均未通过准入**（见 `desk_eligibility.csv`），这是数据量下的
真实结论而非保守过度：

| 桌 | 累计送件 | 误送 | 上界 | min_support | 容忍度 | 结论 |
| --- | --- | --- | --- | --- | --- | --- |
| finance | 11 | 0 | 0.197 | 15 | 0.10 | 支持量不足且上界超标 |
| review | 5 | 0 | 0.351 | 12 | 0.12 | 支持量不足 |
| service | 12 | 0 | 0.184 | 10 | 0.16 | 支持量够但上界超标 |

因此当周所有来件转人工补读或等待，系统不擅自自动定桌。

## 5. 当周分送规则（`routing.py`）

- 只有通过准入的桌才自动接件；OOV、证据不足新子类、v2 上位类一律转 manual；
- 一封信各主题**分别处置**：有充分依据的主题先送达，不等同封所有主题确定
  （x241 的 refund 已送 finance，contact 因 OOV 转人工）；
- **同一来件对同一桌只占一个接件位**（多主题同桌合并，按去重来件计配额）；
- 窗口满或缺席**不丢件、不改投有余位的别的桌**，进 waiting 并带两层原因：
  `reason`（最终：满员/缺席）+ `base_reason`（底层：OOV/无验证办法/上位类）；
- 紧急件（`urgent=1`）按「紧急 → 到达日 → 编号」优先排队；
- 已签收（received 且有 ack）的历史分送原样保留并占名额，只对 waiting 部分重分；
- 任何来件都至少落到一个承接位，绝不出现无桌承接。

## 6. 报告清单（`reports/`）

| 文件 | 用途 |
| --- | --- |
| `method_selection.csv` | 每窗口每主题选中的办法、阈值、独立复核覆盖/误送 |
| `audit_scores.csv` / `select_scores.csv` | 复核段/选型段三办法的漏判、误送、覆盖、OOV 拦截 |
| `slice_scores.csv` | 模板/自由写法 × 单/多主题切片的漏判误判（分开看三类来件） |
| `desk_eligibility.csv` | 桌级累计证据、Wilson 上界、最小支持量、是否准入 |
| `forwarding_audit.csv` | 每窗口转发组角色、关系确认日、是否被训练排除 |
| `routing_plan.csv` | 当周逐主题分送：桌、状态、两层原因、概率、OOV、紧急 |
| `coordinator_view.csv` | 协调员视图：哪些送达、哪些待分及原因，紧急可优先处理 |
| `feature_explanations.csv` | 真正决定分案的特征（logreg 权重/nbayes 似然比/规则短语） |

## 7. 反馈闭环与纪律

- 之后的人工签收、补标、更正可用于**下一次**窗口选型；
- **不能拿预测结果当标注**，也不能拿已用于选型的来件再声称独立改善；
- 目录或承办范围在分送前改变时，已签收桌保留当时收到的主题，
  只对未确认部分按新目录重新分送（由 `route_week` 的 locked/pending 分离实现）。

## 8. 模块结构（`src/appeal/`）

| 模块 | 职责 |
| --- | --- |
| `dataio.py` | CSV 载入与不可变记录 |
| `taxonomy.py` | 目录版本、上位类、承办桌映射、证据继承判定 |
| `groups.py` | 转发组、按窗口的角色划分、组感知成员归并 |
| `labels_view.py` | 时点标签视图、PU 样本、retracted 处理 |
| `features.py` | 请求段切分、字符 n-gram、共享词表、OOV 覆盖率 |
| `models.py` | rule / nbayes / logreg 三候选 |
| `trainer.py` | 按时点训练、弱标注段归因、跨版本证据血缘 |
| `evaluation.py` | 漏判/误判、切片、Wilson 上界、阈值网格 |
| `simulation.py` | 滚动窗口编排、组排除、桌级累计证据与准入 |
| `routing.py` | 当周分送、容量、优先级、已签收保留、协调员视图 |
